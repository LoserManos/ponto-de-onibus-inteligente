# Ferramentas para gestão do projeto

O grupo utilizará o **GitHub** como ferramenta central de apoio ao processo Scrum:

- **Milestones:** uma milestone para cada entrega parcial da disciplina;
- **Issues:** registro de funcionalidades, documentação, defeitos e demais tarefas;
- **Sub-issues:** divisão dos itens maiores da entrega em atividades menores;
- **GitHub Projects:** quadro Kanban que será criado para visualizar o andamento das tarefas;
- **Branches e pull requests:** desenvolvimento separado e revisão antes da integração à branch principal.

## Fluxo inicial de trabalho

Cada issue deve estar associada à milestone correspondente e ter um responsável definido. Quando houver alteração no repositório, a issue também deve apontar para o pull request relacionado. O quadro do GitHub Projects será organizado nas colunas `Backlog`, `Em andamento`, `Em revisão` e `Concluído`.

## Organização das sprints

No começo de cada ciclo, o grupo selecionará os itens prioritários do backlog e, antes de cada entrega, revisará o que foi produzido. Como os integrantes não trabalham no projeto todos os dias, as atividades serão concentradas em uma sessão semanal, com acompanhamento assíncrono pelas issues e pull requests do GitHub.
