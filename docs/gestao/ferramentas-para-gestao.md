# Ferramentas para gestão do projeto

O grupo utilizará o **GitHub** como ferramenta central de apoio ao processo Scrum:

- **Milestones:** uma milestone para cada entrega parcial da disciplina;
- **Issues:** registro de funcionalidades, documentação, defeitos e demais tarefas;
- **Sub-issues:** divisão dos itens maiores da entrega em atividades menores;
- **GitHub Projects:** visualização das issues em um quadro Kanban;
- **Branches e pull requests:** desenvolvimento separado e revisão antes da integração à branch principal.

## Fluxo inicial do quadro

O quadro será organizado nas colunas `Backlog`, `Pronto para Sprint`, `Em andamento`, `Em revisão` e `Concluído`. Cada issue deve estar associada à milestone correspondente e ter um responsável definido. Quando houver alteração no repositório, a issue também deve apontar para o pull request relacionado.

## Organização das sprints

As sprints terão duração inicial de uma semana. No começo de cada ciclo, o grupo selecionará os itens prioritários do backlog; ao final, revisará o que foi produzido e registrará impedimentos e melhorias para a sprint seguinte.
